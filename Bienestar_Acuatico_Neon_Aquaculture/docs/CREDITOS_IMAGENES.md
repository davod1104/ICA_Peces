# Créditos y licencias de imágenes

Las fotografías ilustrativas externas referenciadas por el sitio se cargan desde Wikimedia Commons mediante `Special:FilePath`; se requiere conexión a Internet para mostrarlas. En el entorno de construcción no se pudo descargar esos archivos binarios, por lo que no se presentan como archivos locales. Si una imagen remota no carga, el sitio muestra un fondo de respaldo. Las primeras tres imágenes de la galería sí se guardan localmente.
